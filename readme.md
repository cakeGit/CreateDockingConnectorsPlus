# Create: Docking Connectors+

Additional docking connector variants for Create:

- **Docking Pipe Connector** — a `pipe` port on its back face. When two connectors are docked, the port bridges Create fluid networks across sublevels, so a pump on one side can pull fluid from a tank on the other side.
- **Docking Kinetic Port** — a shaft port on its back face. When two ports are docked, the pair bridges Create kinetic rotation and stress across sublevels with a 1:1 signed speed.

Requires [Create](https://modrinth.com/mod/create) and [Create: Aeronautics](https://modrinth.com/mod/create-aeronautics).
