# More Docking Connectors!

## Docking Kinetic Connector

![Docking Kinetic Connector](https://cdn.modrinth.com/data/22zKNz13/images/fc31baa4e6d05696211b6402882454e8b642b9d9.png)

Adds a type of docking connector that is able to transfer rotational power between sub-levels.

## Docking Pipe Connector

![Docking Pipe Connector](https://cdn.modrinth.com/data/22zKNz13/images/9dbd138770ee4340c5d271e8885fa28e924ccbaa.png)

Adds another type of docking connector that is able to transfer fluids between sub-levels. Specifically, this acts like a fluid pipe, meaning a pump is only required on one side of the connector. Useful for creating a way to interface with a fluid tank that exists as its own sublevel, without adding pumps on either side:

![Example use case of Docking Pipe Connector](https://cdn.modrinth.com/data/22zKNz13/images/d6f852ff4939148a99146c002e1dd117e4ac8bfd.png)

## Additional Functionality

Both of these connectors can only be used for their specific purpose, and you will still want to use normal docking ports for the transfer of items, power or ComputerCraft signals.
